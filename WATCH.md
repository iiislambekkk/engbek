# Lexi Watch

Lexi Watch передаёт субтитры из Stremio Web и YouTube в Lexi, чтобы читать их на телефоне. Для передачи используйте один Tampermonkey userscript; аккаунт Lexi связывается с браузером одноразовым кодом.

## Запуск

1. Установите зависимости (`pnpm install`) и задайте `DATABASE_URL` и остальные переменные окружения Lexi в `.env`.
2. Примените миграции и сгенерируйте Prisma Client:
   ```sh
   pnpm exec prisma migrate deploy --config prisma7.config.ts
   pnpm exec prisma generate --config prisma7.config.ts
   ```
3. Для разработки запустите `pnpm dev` (`node server.mjs`), для production — `pnpm build` и `pnpm start` (`node server.mjs --production`). Именно `server.mjs` обслуживает Next.js и WebSocket `/api/watch/socket`; запускайте один процесс Lexi на выбранном `PORT`.
4. Откройте Lexi на компьютере и телефоне по одному адресу, который доступен обоим устройствам. Откройте `/watch` на компьютере, затем страницу подключения и установите `/lexi-watch.user.js` в Tampermonkey.
5. В Stremio Web или YouTube включите субтитры и нажмите **Send subtitles to Lexi**. В открывшейся вкладке войдите в тот же аккаунт Lexi и подтвердите одноразовый код. Скрипт запоминает подключение для обоих сайтов.
6. Откройте `/watch` на телефоне под тем же аккаунтом. Текущий просмотр обновляет экран субтитров, прошедшие видео доступны в истории. Выберите дорожку при наличии нескольких, нажмите закладку у строки, чтобы сохранить её в **Saved**.

`pnpm dev` и `pnpm start` запускают сервер WebSocket через `server.mjs`; запуск одного `next dev` или `next start` не поднимет этот WebSocket. При другом адресе Lexi используйте меню Tampermonkey **Lexi: change server address**. Для нового hostname также настройте `@connect` userscript и доверенный origin Lexi.

## Известные ограничения

Захват зависит от текста, который отдаёт видеоплеер. Встроенные в изображение субтитры, canvas/ASS, внешние плееры, кастинг и видео без доступных подписей не захватываются; OCR и распознавания речи нет. На Stremio по возможности выберите текстовую дорожку вместо styled ASS. Название, миниатюра, IMDb ID, сезон и серия зависят от метаданных, доступных сайту. Потоковые URL Stremio не передаются.

Автоскрытие панели Tampermonkey работает во время воспроизведения и раскрывается при паузе, движении указателя/нажатии клавиши или при открытии меню Tampermonkey. На мобильном устройстве управлять userscript обычно нужно на компьютере.

## Проверки

Минимальные статические проверки проекта можно запустить командами:

```sh
pnpm exec prisma validate --config prisma7.config.ts
pnpm exec tsc --noEmit
pnpm exec eslint app/api/watch components/watch-live.tsx lib/watch.ts lib/watch-publish.ts server.mjs
```

Статические и автоматизированные проверки не заменяют ручную проверку живого WebSocket на телефоне после сна, настоящего входа/выхода, закладок и захвата в Stremio Web и YouTube. Проверяйте Tampermonkey на реальном видео отдельно.
